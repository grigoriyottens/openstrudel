# Telegram: один бот, разные разговоры

На устройстве работает один Telegram-бот. Общий помощник отвечает сам или привлекает подходящего сотрудника. Подключённый ноутбук управляет тем же устройством и не запускает второго получателя сообщений.

## Начало работы

1. В настройках устройства подключите бота из BotFather и нажмите **Связать мой Telegram**. Нажмите «Начать» в Telegram.
2. Добавьте этого бота в свою группу обычным способом или кнопкой **Добавить бота в группу**. Если его добавляет подтверждённый владелец, группа подключается автоматически.
3. Напишите боту в личку. В новой группе упомяните его или ответьте на его сообщение. Выбирать сотрудника для каждой группы не требуется.

История Telegram находится в **Переписках**, отдельно от списка сотрудников. У каждой группы своя история и файлы. Обсуждение этой истории внутри OpenStrudel остаётся в приложении: подпись над полем ввода показывает место ответа.

Переписки Telegram называются так же, как чаты в Telegram. Чат сотрудника в приложении называется его именем. После переименования сотрудника этот чат получает новое имя, а переписки Telegram сохраняют свои названия. При обновлении Home исправляет и чаты, в которых осталось прежнее имя сотрудника.

Обычное обсуждение новой группы не запускает модель. Сообщения и файлы, которые Telegram передал боту и к которым у него есть доступ, сохраняются как контекст для следующего обращения. Бот не может прочитать сообщения, которые Telegram ему не передал, или историю до его добавления. В частности, режим приватности Telegram влияет на доступные сообщения. Настройки администратора не меняются автоматически.

## Существующие группы

При переносе сохраняются прежний сотрудник, характер, список участников и правила ответа. Например, сотрудник может понимать продолжение разговора без повторного упоминания. Любой такой сотрудник тоже может привлечь специалиста; это не переносит разговор и не подключает его личные сервисы к группе.

Пауза доступна в карточке группы. Удаление бота из Telegram также приостанавливает ответы; история остаётся. Переход в супергруппу сохраняет рабочие данные. Форумные темы пока не поддерживаются: их сообщения не смешиваются с общей группой.

## Доступ

- Настраивать бота может владелец устройства. Добавление бота посторонним человеком не открывает доступ к сотрудникам и сервисам.
- Новая группа принимает обращения своих участников; импортированные группы сохраняют прежний список доступа. Обновление не расширяет его.
- Помощник и приглашённый им сотрудник используют контекст текущей группы. Личные чаты, файлы и подключения остаются отдельно.
- Рабочий сервис сам проверяет отправителя и место разговора. Доступный в личке инструмент может быть ограничен в группе. Приложение не подменяет отправителя владельцем.
- У каждого Strudel есть список доступа: Telegram ID людей, которым доступно всё. Владелец, связавший свой Telegram, в нём всегда. Люди из списка не получают прав владельца.
- Остальные участники группы получают ответы по этому чату, его файлам и открытым источникам. Сервисы с ключом владельца или группы, приложения ChatGPT, память и помощники для них не работают. Работают только сервисы, которые сами проверяют отправителя.
- Расписания в группе настраивают только люди из списка доступа. Каждый видит и меняет расписания своего чата.
- Владелец видит, меняет и останавливает любые расписания этого Strudel из любого чата: из группы, из лички или из приложения.
- В группе помощник запускает команды в песочнице и меняет файлы только в рабочей папке этой группы. Так работают и Codex, и Claude. Выйти за песочницу нельзя ни в каком режиме.
- Одноразовая ссылка личного подключения действует 10 минут. Подключённый Mac или сервер должен быть включён.

## Расширенные команды

```sh
openstrudel telegram status
openstrudel telegram pair
openstrudel telegram group EMPLOYEE_ID
openstrudel telegram group EMPLOYEE_ID --device DEVICE_ID
```

Последние две команды оставлены для явного подключения определённого сотрудника и совместимости существующих настроек. Это дополнительная возможность, а не обязательный шаг обычной настройки.

Список доступа:

```sh
openstrudel access
openstrudel access set 139287108 241196252
```

`access set` заменяет весь список; без ID он очищает его.
