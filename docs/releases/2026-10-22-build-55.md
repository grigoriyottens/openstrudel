# OpenStrudel 1.0 (55)

Source: `0ab06e9b7fa4b721b88f6c539cac7f32ade2280e` (PR #57).

Services connected in the owner's main chat can be shared with every employee
and Telegram group on a Home (`openstrudel services all-chats on`). App grants
live only in each chat's shared configuration, connecting an app works inside a
chat again, and the OpenAI app directory no longer delays service lists.
Technical failures go to the owner privately instead of group chats. An
exhausted ElevenLabs quota is reported as a limit. Details and the live state:
[integrations in every chat](../operations/integrations-2026-10-22.md).

## Live repairs

- Sharing is on for all three servers. Each main chat has company, mik-mcp,
  WAI personal and WAI Telegram, plus Gmail, Google Calendar, Google Drive,
  Google Contacts, Notion, Linear, Slack, GitHub, Figma, Canva and Spotify.
  All 36 chat audiences listed every one of them as ready.
- Grisha's meeting request in "wai team", refused on 21 October, was completed
  by the bot: a Google Calendar event with Meet for 22 October 15:30–16:00 MSK,
  inviting only Grisha and Dima, announced in the group (message 1152).

## Release verification

- Typecheck and 635 tests passed. `tests/messages.test.ts` "shows a readable
  startup timeout" fails identically on the previous main.
- The app is signed, notarized, stapled and accepted by Gatekeeper; the five
  packaged-runtime and installer tests passed. Downloads, stable aliases and
  checksums were verified over HTTPS. The Sparkle feed and archive signatures
  verify; feed history keeps builds 54–49.
- The installed Mac updated from 54 to 55 through Sparkle's own download,
  installation and relaunch. Its executable and bundled runtime match the
  staged release, its signature verifies, and the rendered Devices screen shows
  all three servers online. The local rollback snapshot was marked healthy.
- Wolf and WaiClaw run `openstrudel:55-0ab06e9`. Grant runs
  `openstrudel:54-b9d51b1`, whose compiled runtime is byte-identical to build
  55: its 55 relabel was refused because the disk (95% full) has no room for a
  rollback snapshot. Twelve older snapshots back to build 43 use about 22 GB.
- Anthropic API keys were added on all three servers; a direct API call with
  each key answered from Claude Haiku 5.5 and Claude Fable 5.1. No chat uses
  Anthropic yet; quota limits do not switch providers.
