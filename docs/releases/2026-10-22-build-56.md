# OpenStrudel 1.0 (56)

Source: `e9baa7b730d15dbfa4092b3b75ea539a5f1dbbad` (PRs #58, #59, #60).

Claude by API key now works in private and employee chats on servers, and
server upgrades keep their rollback material bounded.

- **Claude sandbox on Linux.** Claude Code's sandbox needs `socat` next to
  `bubblewrap`. Without it every private and employee chat on Anthropic failed;
  group chats, which run no commands, still answered. The image installs it.
- **Lost Claude sessions.** A turn that failed before Claude Code wrote its
  session left the id saved, and every later turn in that chat failed with
  "No conversation found with session ID". Like a lost Grok session, the chat
  now starts once in a new session seeded with its history.
- **Rollback retention.** `scripts/prune-server-rollbacks.py` keeps the two
  newest healthy upgrade snapshots, anything newer, the images they roll back
  to and the running image. The release installer runs it before a snapshot and
  after the health check. A first 56 attempt rolled back on Wolf and WaiClaw
  because the pruner removed the just-built image; images newer than the oldest
  kept snapshot are now kept (#59).

## Live changes
