# OpenStrudel 1.0 (57)

Source: `5ebd16544769d38cc1a52053a433cd7b59b841b9` (PR #61).

On the Claude engine every group turn was denied commands and file changes,
including the owner's own scheduled jobs. Once the device default moved to
Claude, WAI News stopped publishing at 09:30 MSK ("Commands and file changes
are not available in a group chat"), and so would the other pipelines that run
in their group (Wai Connect, Рецепт дня, Важные даты, the wishlist). A
scheduled run in a group now gets the owner chat's sandboxed commands; live
turns from group members still run none.

## Release verification

- Full suite passes except the known `messages.test.ts` startup-timeout case;
  `home.test.ts` speech relay failed once under load and passes alone (3/3).
- All three servers run `openstrudel:57-5ebd165`, deployed with health and data
  checks; rollback retention ran in each installer.
- The 15:30 UTC WAI News run on WaiClaw published four source-linked cards
  (Telegram messages 10290–10293), its first publication since 09:30 MSK.
- The app is signed, notarized and accepted by Gatekeeper; packaged tests pass.
  Downloads and the Sparkle feed were verified over HTTPS. The installed Mac
  updated 56 → 57 through Sparkle; executable and runtime match the release.
