# OpenStrudel 1.0 (59)

Runtime source: `b07c4deda5216be0157728642f508b7e82d576da` (PRs #63 and #64).

Each Home now has one access list. Listed Telegram senders can use its private
services on Claude and ChatGPT. The owner can manage employees' schedules from
any chat, and Claude can work with documents inside a group's own workspace.

Scheduled work can return `FAILED: <reason>`. The run is recorded as failed,
the group stays quiet, and the owner receives a private notice. Repeated failures
retain the existing notice deduplication until a successful run resolves them.
