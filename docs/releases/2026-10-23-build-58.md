# OpenStrudel 1.0 (58)

Source: `eddbf7ea3c77b10f2a311877480f566e6dcb5399` (PR #62).

A week of bot traffic showed group answers aimed at the wrong message, several
answers to one burst, ignored edits and reviews of every captionless file.
Group turns now get what a person in the chat sees.

- **Reply target.** A group turn carries the message it replies to: author,
  quote or text, caption, or the file name. The assistant answers that message,
  in a thread.
- **Bursts and edits.** A queued group turn sees the newer messages that already
  arrived and answers once. An edit updates a message still waiting its turn.
- **Files.** A file without a caption is context, not a request to review it.
- **Provider switch.** The history a new provider starts from keeps authors and
  file names.
- **Claude parity.** Per-service tool lists and env credentials from the Codex
  configuration apply on Claude, and WAI News urgent operations run sandboxed
  like schedules.
- **Group rules.** The owner can change a group employee's rules from the group.
- **Owner notices.** One notice per cause in 12 hours, and no recovery messages.
