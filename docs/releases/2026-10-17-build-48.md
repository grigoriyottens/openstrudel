# Build 48 — dictation, chat models and device connections

Release source: `fb84d3df8a31f5fa1be181083481e29123b139e0` on main.

## Delivered

- A Home can use local recognition or ElevenLabs. The selected service handles
  native dictation and supported audio/video uploads. Telegram and app uploads
  show a transcript before the employee's answer; native dictation remains an
  editable draft until explicitly sent. Failed/cancelled native recognition
  retains the recording. Optional speech generation uses the existing file and
  Telegram delivery path.
- Model, speed and reasoning can be selected for one conversation, inheriting
  from its employee and device when no override is set. Options come from the
  actual provider catalogue. A change affects subsequent work, including queued
  messages, without changing unrelated chats or employee defaults.
- Dictation stays attached to the Home chosen when recording begins. Scoped
  model writes cannot accidentally change an older Home's device-wide default.
- iPhone connection removal is saved before remote logout; late responses cannot
  resurrect removed connections. QR and link entry points share the same review
  flow. HTTPS invitations support Universal Links and retain credentials in the
  fragment. The iOS pairing action remains reachable at the largest text size.
