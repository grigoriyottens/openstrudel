## Changes

### Service errors and action approvals

The English Mac interface displayed an untranslated service-catalog error and Russian action-approval controls. Service errors now retain their context and refresh action in all five interface languages. The connected-service list no longer hides its notice based on a comparison between a server message and a translated prefix.

Approval titles, questions and choices use the shared localization catalog. The application submits the original option value, so translating Allow or Deny does not change the backend decision. Provider descriptions, arguments and unknown text remain unchanged. Fixed, application-owned service descriptions are translated.

Real provider diagnosis distinguishes the catalog from installed connections: `app/installed` returned 21 apps in about 1.3 seconds, while `app/list` returned an HTTP 403 provider challenge in about 0.3 seconds. Existing connections remained usable. No timeout increase, challenge bypass or forced disconnect was used.

### Portable runtime packaging

A signed and notarized build 41 candidate failed the actual installation check: the GUI launched, but its bundled Home could not start. The packaging script had copied this machine's Homebrew Node, which depended on an unavailable `@rpath/libnode.141.dylib` and other Homebrew libraries.

The packager now downloads the official Node **26.7.0** archive for the app's architecture, verifies its pinned SHA-256, includes the Node license, rejects non-system linked libraries and executes a SQLite smoke check before replacing the staged runtime. Node itself is included in the runtime digest. This keeps the same standalone Node version already used by the working public build 40.

Release instructions explicitly select a single architecture: a macOS destination alone did not prevent Xcode from building both architectures. The packager rejects an architecture mismatch instead of silently shipping the wrong runtime. A new finished-bundle regression executes the signed Node, SQLite, crypto and launch-agent generator with only system tools on PATH.
