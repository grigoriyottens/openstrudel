# OpenStrudel 1.0 (53)

Source: `997bd20198d02f61a0beb62237027d7f781085f0`.

Account and execution failures now reach the paired owner through the existing
Telegram bot, including failures in the main chat and scheduled delivery.
The same unresolved problem produces one notice; a successful later task sends
one recovery notice. Group participants do not receive these operational notices.
Intentional cancellation does not raise an incident. An unconfirmed Telegram
delivery remains unresolved and is not replayed automatically.

The implementation reuses root-chat notices and the durable Telegram outbox.
It adds no notification service, agent loop or polling job. If notification
delivery itself fails, the original problem remains saved in the main chat.

contexts, with the same configured server and scope. Native `notion_get_self`

and native `search_chats` and `get_chat_messages` passed. Group configurations

  retain one shared publication claim ledger.

  The existing reserve schedule now runs a broader review every 15 minutes.

  OpenAI/Orchestra Bio and Gradium/Phonon cards reached Telegram and their numeric
  receipts were recorded. The later automatic review delivered DeepInfer and
  Kodiak cards without manual story requests. The scheduled run finished quietly
  after its individual posts.
