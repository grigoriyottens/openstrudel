## Incident findings and recovery

- WaiClaw still ran the old migration image with local transcription and no
  ElevenLabs configuration. The cloud integration on another server did not
  change this deployment. WaiClaw now runs build 50 with ElevenLabs Scribe v2.
- Grant's server and data were present. Its connection had been signed out in

  does not establish who or what removed it. A fresh owner pairing restored the
  connection; network loss alone was not reproduced as a device-removal cause.
- WaiClaw, Wolf Wolf and Grant were backed up and updated independently. All
  three return healthy status, speech/diagnostics capability version 1 and a
  running Telegram adapter. SQLite integrity checks pass. Existing profiles,
  conversations, messages and schedules were preserved. Grant retains its
  existing local speech setting; WaiClaw and Wolf use ElevenLabs.

## Product changes

- Devices use aligned trailing disclosure arrows, visible connection states and
  direct access to connection testing, speech settings and diagnostics.
- A persistent journal records connection transitions, explicit removal and
  transcription results. Standard logging is the default; detailed mode adds
  operation starts and request timing. The owner can refresh and export it.
- Journals retain up to 200 server events and 100 local events per device.
  Logged fields are bounded metadata: category, provider, byte count, duration,
  HTTP status and safe failure reason. Keys, recordings, transcripts and message
  text are excluded. Local history remains available when the server is offline.
- Provider authentication, quota, network and timeout failures have distinct
  safe diagnostics. Mac and iOS layouts support larger accessibility text;
  the iPad invitation sheet uses an appropriately sized form presentation.
